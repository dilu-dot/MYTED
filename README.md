# TEDDY

Live website: https://teddy-v2.vercel.app/

The GitHub Pages entry redirects to the hosted app, which includes the panda intro, personal letter, six-photo story, date planner, cake celebration and hosted response backend.

The canonical editable project is [connected/](connected/README.md). Build and test it with:

```sh
cd connected
npm run install:frontend
npm run build
npm run check:frontend
npm run test:backend
```

Private owner access requires the configured owner email and site password. The private celebration design, passwords, cloud configuration and saved responses are not in this public repository. See [hosting verification](connected/HOSTING-STATUS.md).

The earlier root source remains in history and in legacy files; use connected/ for current development. The root index is only the GitHub Pages redirect.
